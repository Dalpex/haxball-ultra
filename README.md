# **HaxBall Ultra**

🚀 **HaxBall Ultra** es una aplicación de escritorio creada con **Electron** que mejora la experiencia visual y funcional de HaxBall, ofreciendo una interfaz personalizada, más limpia y moderna, optimizada para una mejor jugabilidad y estética.

---

## ✨ Características

- 🎨 **Tema visual personalizado**
  - Fondo con degradado violeta.
  - Room list con estilo oscuro y detalles en violeta.
  - Botones rediseñados con estética uniforme.
  - Eliminación de elementos visuales innecesarios.

- ⚡ **Optimización visual**
  - Eliminación de barra inferior y elementos molestos.
  - Eliminación de anuncios y barras laterales.
  - Ajuste automático del juego a pantalla completa.

- 🖥️ **Aplicación de escritorio (sin navegador)**
  - Corre HaxBall dentro de una ventana de Electron.
  - Mejor integración con el sistema.
  - Más control sobre el diseño y la experiencia.

- 🎮 **Integración con Discord (Rich Presence)**
  - Muestra actividad como:
    - "Jugando HaxBall Ultra"
    - "En el menú principal"
  - Iconos personalizados en Discord.

---

## 🛠️ Tecnologías utilizadas

* **Electron.js** — Para la aplicación de escritorio
* **JavaScript** — Lógica principal
* **Discord RPC** — Para actividad personalizada en Discord
* **CSS inyectado dinámicamente** — Para el rediseño visual de HaxBall

---

## 🎯 Objetivo del proyecto

HaxBall Ultra busca:

* Modernizar la apariencia de HaxBall.
* Eliminar distracciones visuales como anuncios.
* Ofrecer una jugabilidad con menos delay y mayor rendimiento.
* Integrarse mejor con Discord y el sistema operativo.

---

## ⚠️ Notas importantes

* Esta app **no modifica los archivos originales de HaxBall**.
* Solo aplica cambios visuales dentro del iframe del juego.
* No es un cheat, mod de jugabilidad ni hack.
